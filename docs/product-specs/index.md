## 位置づけ

OpenAI / Anthropic / Gemini / OpenAI 互換サーバーを同じコードで呼べる、**軽量なクライアント**。対象は、自分でエージェントや LLM を組み込んだアプリを書く Python 開発者。

- エージェントフレームワークではない（ループの制御や記憶は利用者が書く）
- ゲートウェイやプロキシではない（サーバーを立てない）
- ランタイム依存は httpx だけ

なぜ作るのかは [基本方針](../design-docs/core-beliefs.md)、既存ライブラリとの比較は [README](../../README.md) にある。
