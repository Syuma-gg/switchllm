## 判断ログ

- 2026-11-09: 機能を絞った軽量ライブラリとして出す。使い心地は下げない（[軽量化の記録](../completed/2026-11-09-lightweight-and-docs.md)）
- 2026-11-14: パッケージ名と import 名を `switchllm` にする。PyPI で区切り文字の違う形も含めて空いていて、「文字列でプロバイダーを切り替える」という中心の機能をそのまま表すため。`llmswitch` は既存の `llm-switch`（設定ファイルでプロバイダーを切り替えるライブラリ。2025-04 から更新なし）と似すぎていて断られる見込みのため外した。GitHub には自動ルーティング用プロキシに同じ名前を使う小さなリポジトリがあるので、README の冒頭で「自動では切り替えない。文字列で選ぶ」ことをはっきり書く（フォールバックは [scope.md](../../product-specs/scope.md) で「やらないこと」）
- 2026-11-14: 基底例外の `UniLLMError` も `SwitchLLMError` に変え、旧名の別名は残さない。まだどこにも公開していないので、旧名で書かれた利用者のコードはない
- 2026-11-14: ライセンスは MIT、著作権者は `Syuma-gg` にする。他人のアプリに組み込んで使うライブラリなので、条件がゆるいほど使ってもらいやすい。Python の小さなライブラリで最も広く使われていて、唯一の依存の `httpx`（BSD）とも問題なく組み合わせられる。Apache-2.0 の特許条項が効くのは大きな会社が関わる規模で、GPL 系は派生物の公開を求めるので、会社では避けられやすい
- 2026-11-14: 版の正本は `__init__.py` に置き、`pyproject.toml` がそれを読む形にする。逆向き（`importlib.metadata.version()` で `__version__` を作る）は、インストールせずに `src/` から動かしたとき（pytest の `pythonpath = ["src"]`）に失敗するため
- 2026-11-14: CI は、Ubuntu では対応する Python の全版（3.10〜3.15）、Windows では最古版と最新版だけで回す。作者の開発環境が Windows なので Windows でも確かめたいが、全版を回すとジョブが倍になるのに見つかる問題はほとんど増えないため
- 2026-11-14: 開発段階の classifier は `3 - Alpha` にする。モックのテストは揃っているが、実 API ではまだ確かめていないため。[実 API 検証](real-api-verification.md) が終わったら `4 - Beta` にするか見直す
